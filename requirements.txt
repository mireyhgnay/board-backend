# 📌 requirements.txt - 프로젝트 의존성 패키지 목록
#
# 【 설치 방법 】
#     1. 가상환경 생성 및 활성화:
#         python -m venv venv
#         source venv/bin/activate  (Mac/Linux)
#         venv\Scripts\activate     (Windows)
#
#     2. 패키지 설치:
#         pip install -r requirements.txt
#
# 【 패키지 추가 시 】
#     pip install 패키지명
#     pip freeze > requirements.txt  (현재 설치된 패키지 목록 저장)
#
# 【 가상환경이란? 】
#     프로젝트마다 독립적인 Python 환경을 만드는 도구입니다.
#     Node.js의 node_modules와 비슷한 개념입니다.
#     프로젝트A는 패키지 v1.0, 프로젝트B는 패키지 v2.0을 각각 사용 가능합니다.
